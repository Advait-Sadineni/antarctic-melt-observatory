Strategic design & roadmap · 2026

The Antarctic
Meltwater Observatory

A plan to grow a validated single-shelf melt detector into the first open, cloud-proof, volume-aware tool for watching surface meltwater across Antarctica — a living instrument, not another static dataset.

Pick any ice shelf, any date → how much meltwater is on it (area and volume), gap-free and year-round, from free satellites.

Starting point: George VI detector — blind-validated, cloud-robust, 9-season record

What's already built

The starting line

This isn't a plan from zero. The George VI pipeline is done, validated three independent ways, and has produced a cloud-robust 9-season record — all from free data.

  • Published detection method — Moussavi NDWI + shadow test + hysteresis, chosen by scoring 9 candidates, not hand-tuned
  • Blind-label validation — precision 0.63; bias-corrected true water 157 ± 37 km²

  • 46 offline tests — reproducible, version-controlled, fully open

The gap it fills

Why now

The field has the pieces — but they live in separate papers as static file dumps. Nobody has stitched them into one usable whole. That integration is the opening.

Optical area
mature, now continent-wide — no longer novel alone
SAR melt (Sentinel-1)
sees through cloud & polar night — but siloed
Depth / volume
emerging; ICESat-2 hard at scale
fuse
One integrated observatory
optical + SAR fused → gap-free & year-round · depth → volume · open, queryable, reproducible · region-agnostic

A circum-Antarctic spatio-temporal record is "entirely lacking" and Antarctic lakes remain understudied vs. crowded Greenland. NSIDC's near-real-time melt service was defunded in Oct 2025 — demand is real, and funded tools die. The edge is integration + accessibility + rigor, and a design that survives on near-zero cost.

Regret-proofing

Get the few irreversible calls right

Regret comes from a handful of foundational choices — not the dashboard library. Lock those in now; keep everything else cheap to change.

Locked in now · irreversible

Get these right

  1. Backend-agnostic science core — portable Python behind swappable adapters. The keystone; makes the backend choice reversible.
  2. Full-vision data model on day one — multi-sensor, area + volume + uncertainty, open standards. Filled incrementally; never migrated.
  3. Region-agnostic — Antarctica now, Greenland or any glacier later for free.
  4. Open source + open data from commit #1 — can't retro-open a closed thing.
  5. Near-zero running cost — serverless/static; survives with no funding.
Decide later · reversible

Don't agonize

  • Exact compute backend (Planetary Computer vs Earth Engine)
  • Threshold vs ML detector — pluggable behind the same interface
  • Dashboard & API stack
  • Depth-retrieval algorithm
  • Which shelf first

+ a decision log records every foundational call with its alternatives — so revisiting is deliberate, not second-guessing.
