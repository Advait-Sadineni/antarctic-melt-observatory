How the observatory works

From satellite photons to next-summer predictions — seven stages and the two loops that make it science.

built & validated running now roadmap
1🛰️

SENSE

satellites photograph Antarctica every few days

BUILTSentinel-2 optical — sees pond area in color; blocked by cloud
M3Sentinel-1 radar — sees through cloud & polar night → gap-free record
M4ICESat-2 laser — samples pond depth → volume in km³
2💧

DETECT

find the liquid water in every image

BUILTWater index (NDWI) + shadow test — water absorbs infrared, snow doesn't; published method
BUILTCloud-robust scene picking — haze mimics water; we measure actual cloud over the shelf and refuse to be fooled
3🔍

VALIDATE

never trust your own detector

BUILTBlind human labels — 80 hidden test points per shelf; George VI 0.63 · Larsen C 0.60 precision
BUILTCross-satellite check — independent Landsat-8 agrees, r = 0.92
BUILTLiterature match — independently reproduces the published 2019-20 record
🔁

THE ACCURACY LOOP — runs forever. Every validation finding flows back into detection. Yesterday's example: Larsen C's "water" turned out ~40% slush → east-side shelves now get a correction band. The system gets more honest every cycle.

4📚

RECORD

the measurement baseline — you are here

RUNNING10+ shelves × 9 seasons — every year on the same fixed grid, so years are truly comparable
STARTEDOpen data products — every season auto-saves as cloud-ready files (COG + STAC) → future DOI'd dataset
5🌡️

EXPLAIN

add the weather — what drove each melt year?

NEXTClimate records (ERA5) — temperature, wind, sunshine for every shelf-season we measured
EMERGINGPatterns — already visible: GVI + Wilkins spiked together in '19-20; Bach & Stange setting records right now
6🔮

PREDICT

the payoff — forecast melt before it happens

ROADMAPTrain: melt = f(climate) — the whole multi-shelf record becomes training data
ROADMAPForecast next summer — feed climate forecasts through the trained model
🎓

THE GRADING LOOP. Every new melt season is a fresh exam: prediction vs what actually happened. Wrong → retrain. Right → the model earns trust. This is what separates a forecast from a guess.

7🌍

SHARE & WARN

make it usable — the one-of-a-kind part

M5Vulnerability warnings — % of shelf ponded + sudden lake drainage = hydrofracture precursors
M5Open dashboard + API + DOI — any researcher picks a shelf and a year; the tool the field doesn't have
